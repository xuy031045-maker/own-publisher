# 自有发布台 V1 验收记录

日期：2026 年 11 月 15 日。V1 功能冻结，进入个人运营；后续以安全修复和平台兼容维护为主。本轮没有新增功能、重构或开发新的智能体。

## 本轮修复

- 私信提醒的确认基准只根据已核验消息的时间推进，不采用可能领先的会话列表时间。旧基准如高于已确认消息，读取会话时会按已有确认锚点保守修正；旧版快速同步缓存会重新核对。
- 当前消息窗口缺项、无法对应或最新消息缺少可信时间时，不把未核验的数据用于推进基准。无法确认的消息保持待核对。
- 自动同步的下一次计划从任务结束时起计算；任务异常中断或结束状态无法记录时，从恢复检查时起等待一个间隔。更改间隔、关闭同步以及过期任务令牌均有测试覆盖。

## 验证结果和范围

- **自动化回归：**8 个 Python 测试模块共 152 项通过，前端私信提醒测试通过。测试使用隔离的临时数据库与模拟平台操作，没有向平台提交作品或发送私信。
- **隔离回归：**覆盖列表时间领先、旧基准过大、基准缺失、未对应消息、缺少最新消息时间、旧缓存重新核验、重复同步，以及长时间排队后的完成、中断、取消和间隔变更。
- **真实只读核验：**新版启动后，使用已登录的两个账号连续同步两次；账号和会话可读取，两次均无会话读取错误，已有新消息及待核对提醒数量没有重复增长。部分历史仍未完整核实。
- **验证边界：**本轮没有人为制造新的真实私信，也没有重新提交作品。实际新来信触发提醒及真实发布曾在此前验收中验证；本次时间领先和长时间排队边界由隔离回归验证。平台页面变化或登录过期仍可能影响同步，不能保证找回旧版本期间已漏掉的提醒。

## 数据与运营

正式数据库和备份保留，升级前创建了一份新的数据库备份；确定属于模拟测试的临时数据库已移入回收站。涉及真实登录资料的临时目录未按普通测试文件处理。日常使用时保持工作台和电脑运行，关注登录状态及“需要核对”的会话；发布前仍须本人确认，私信由本人跟进。
