# 自有发布台：项目汇总与验收

自有发布台是一个运行在 Windows 本机的图文发布与私信整理工作台。它面向单人多账号使用：先准备并核对内容，再由本人确认发布；私信集中查看，后续沟通仍由本人手动完成。

## 现有能力

- **多账号图文：**小红书账号使用相互隔离的 Edge 登录资料；单批最多选择 10 个账号，支持图片排序、逐账号调整文字和时间、立即发布与平台定时发布。
- **发布记录：**逐账号保存预览和提交状态；需要时只读核对平台作品，结果不确定时提示人工检查。
- **私信收件箱：**读取已登录网页中可见的单人会话，支持按账号、关键词与处理状态筛选。新来信可将已处理会话恢复为待处理；重复同步不会对同一条消息反复提醒。
- **同步与队列：**提供快速同步、完整历史同步和可选的低频定时同步。发布、同步、登录检查和打开原会话共用浏览器任务队列；等待中的任务可以取消。
- **本地备份与恢复：**恢复前自动备份当前数据库，并锁住发布；核对平台作品并由本人确认后才可继续。恢复前已有提交或待核对记录的相同图文会继续拦截。
- **智能体接口：**通过 MCP 提供账号、预览、发布状态及私信查询工具。私信查询保留稳定会话标识、消息标识、时间和完整性标记；真实发布仍须本人确认批次。

## 启动与使用

准备 Python 3.11、uv 和 Microsoft Edge，按 [README](../README.md) 安装依赖，然后在项目目录双击 `启动工作台.bat`。首次登录和身份核验需要本人在独立的 Edge 窗口完成。关闭工作台或让电脑休眠后，自动同步不会继续运行；新安装默认不启用定时同步。

运行数据默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\OwnPublisher`，包括数据库和账号浏览器资料。仓库只备份项目源码与说明，不包含登录资料、私信、发布数据库、备份文件或实际图片素材。

## 安全和使用边界

- 私信读取依赖本人已登录的小红书网页，是非官方方式；页面改版、登录过期或平台限制可能影响同步。打开未读会话可能使平台标记为已读。
- 平台没有完整展示的消息不会被当作已读取；无法核实时，工作台保留确认基准并提示检查。语音、部分图片与卡片需要在原会话查看。
- 程序不自动发送或回复私信。发布须先检查预览并明确确认；结果不明时应先到平台核对，不要直接重发。
- 数据库备份不包含独立 Edge 登录资料、数据库外图片或独立防重复记录 `restore-guard.sqlite3`；换机时请关闭程序并一并妥善保管。请使用工作台恢复，不要手动覆盖数据库。

## 验收情况

截至 2026 年 11 月 15 日：

- 项目 8 个测试模块共 **141 项通过**；另有前端提醒并发测试和脚本语法检查。
- 两个真实账号完成私信同步和用户手动测试：已处理会话收到新来信后恢复待处理；重复同步不增加同一条提醒；发出的消息没有被误判为来信。
- 已验证定时同步、浏览器任务等待与取消；任务异常退出和同步任务合并通过隔离测试。
- 旧备份恢复防重复、重复提交拦截及人工验证后的续接通过隔离测试；没有为此次验收重新发布真实作品或触发真实验证码。
- 部分历史消息未能从网页完整核实，工作台会显示相关提示；真实平台的长期可用性仍取决于登录状态和页面变化。
