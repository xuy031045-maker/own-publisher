# 自有发布台

Windows 本地图文发布器。工作台支持小红书账号管理、图文预览、立即发布、平台定时发布和逐账号记录。单批最多选择 10 个账号。已有 CLI 和 Codex MCP 接口继续保留。

当前快照为 **v1.1.0**，在保留 V1 的基础上支持真实昵称展示和私信本机批量删除。项目能力和运行边界见 [项目汇总与验收](./docs/项目汇总.md)，本次验证见 [私信功能验收](./docs/本机删除与昵称验收.md)，历史版本见 [V1 验收记录](./docs/V1-验收记录.md)。

## 打开工作台

在项目目录双击 `启动工作台.bat`。程序会打开浏览器并分配一个本机地址；保持启动窗口运行即可。关闭启动窗口会停止工作台，已经提交给小红书的定时笔记由平台按计划执行。

1. 在「账号管理」登记别名并登录，确认 Edge 窗口中的平台账号。登录或检查后，工作台记录该账号的身份摘要并显示上次核验到的平台昵称；更换账号后请重新检查。
2. 在「新建图文」选择图片、填写文案和话题，选择一个或多个账号。点击缩略图可以查看完整图片，通过左右按钮排序，第一张作为封面。支持 JPG、JPEG、PNG、WebP，单张不超过 32 MB，最多 18 张。选中账号后，可以在「各账号单独设置」修改其标题、正文、话题和发布时间；图片与声明仍共用。
3. 按实际内容选择内容类型。若声明原创，先阅读并同意平台须知。转载需要填写媒体名称；自主拍摄需要填写小红书中的地点名称和拍摄日期，同名地点可用完整地址区分。定时发布按北京时间设置，范围为未来 1 小时至 14 天。
4. 点击「生成发布预览」，核对每个账号、图片、文案、声明和时间，勾选确认后提交。发布前会再次核对登录的账号；若账号身份发生变化，请检查账号并重新生成预览。
5. 在「发布记录」或「定时计划」查看逐账号结果。账号页可编辑本地备注，并显示上次核验时间；记录页可按关键词、账号和状态筛选。带有账号身份快照的提交记录可点击「核对平台状态」：工作台读取该账号的笔记列表，按照标题、时间和有序图片缩略图寻找唯一匹配，记录作品 ID 及平台显示的排期、审核中、未通过或已发布状态。已有作品 ID 时优先按 ID 核对；无 ID 时最多检查 20 页，未能完整检查或唯一匹配会要求人工核对。缩略图只用于辅助匹配，旧记录缺少身份快照时仍须手动核对。

如果页面提示需要登录或验证，请在打开的 Edge 窗口完成操作，登录与预览时相同的账号。登录及小红书人工验证最长等待 10 分钟，也可在工作台取消；提交前取消可以处理后重试，尝试提交后取消或超时会标记为待核对，并停止处理后续账号。如果完成验证后仍在等待，可以点击「已完成验证，继续等待」。只有平台明确返回上次请求被验证拦截时，程序才会在验证后最多再次提交一次；结果不明时不会自动重发。如果窗口关闭或工作台中断导致结果不明，先到小红书笔记管理核对，再在记录中标记核对结果。

选择账号、查看私信来源和发布记录时，主名称使用已核验的平台昵称，系统别名作为辅助信息。尚未核验昵称时显示「未核验」，请在账号管理中检查账号。

工作台使用本机服务，素材和任务保存在 `%LOCALAPPDATA%\OwnPublisher`。账号浏览器资料也在该目录中。请勿把这些目录上传或分享给他人。

## 私信收件箱

在工作台选择「私信收件箱」，使用「快速同步」或「完整历史同步」；也可以先筛选一个账号。每次最多同步 10 个已登记的小红书账号。同步前需在账号管理中检查账号，确保身份已核验。会话、文字和网页中可读取的部分图片、表情保存在本机 SQLite 数据库中；重复同步按账号身份和消息编号去重，不删除此前已保存的记录。

这是通过本人已登录的小红书网页读取的**非官方方式**，不是小红书开放平台授权接口，可能受平台规则或页面改版影响。打开未读会话可能让平台标记为已读。程序不自动发送消息或回复；需要跟进时点击「打开原会话」，在该账号独立窗口中手动操作。发布、同步和打开原会话按顺序排队，可在顶部「浏览器任务」查看或取消等待的任务；原会话关闭后后续任务才会继续。平台要求登录或人工验证时，请本人处理，不会自动绕过。[小红书用户协议](https://agree.xiaohongshu.com/h5/terms/ZXXY20220331001/-1)

列表支持按账号、关键词和处理状态筛选，并可在本机标记待处理、已处理或重要客户；这些标记不改变小红书中的状态。只读取网页实际展示的单人会话（包含陌生人私信），不包含群聊。语音、部分卡片和未能读取的图片仍需到原会话查看；已保存的图片可能是网页加载的缩略图，不一定是原图。不会保存图片 URL 或登录凭据到消息表。数据库和账号浏览器资料包含敏感信息，请勿上传或共享。

可在消息旁删除单条消息，或在会话顶部删除整个会话；两种操作都需要确认。删除只影响本机显示，不删除小红书中的消息。工作台保留本地删除记录并隐藏旧内容，快速和完整同步都不会重新写回已删除消息；删除整个会话后，只有能核验为删除之后的新消息才会让它重新出现。平台时间或消息顺序无法确认时会保守处理，并提示同步结果需要核对。

要一次删除多个会话，可在收件箱点「批量选择」，逐个勾选或「全选筛选结果」，再点「删除所选」并确认；全选包含筛选结果中尚未加载的会话。要批量删除消息，可打开会话后点「批量选择消息」，勾选或「全选本地消息」再删除；全选包含已同步但尚未加载到页面的消息。单次最多选择 10000 个会话或消息，更多时请分批处理。筛选条件改变会清空会话选择；如果所选会话在删除前收到新变化，会停止整批删除并提示刷新核对。浏览器任务或同步正在运行时，请等任务结束后再删除。

同一平台账号若使用多个本地别名，删除记录会在这些别名间共用。删除整个会话时，若另一别名包含当前会话尚未核对的消息，工作台会阻止删除并提示先同步。

同一平台账号的多个别名如果都同步了同一会话，MCP 的稳定会话键会因无法唯一定位而拒绝查询；可使用各条会话的数字 ID 查询，或避免为同一账号重复配置别名。

安装更新后需重启工作台；使用 MCP 的旧 Codex 会话也需重新打开，才能让私信查询使用新版删除过滤规则。旧进程退出前，不要依赖它隐藏已删除内容。

这里采用软删除：消息内容和删除记录可能仍保存在本机数据库或此前的备份中，并非安全擦除。恢复删除操作之前的旧备份，会回到该备份保存的状态，删除记录也可能随之回退；恢复后请核对本机收件箱。

收到可确认的新消息后，已处理会话会重新变为待处理，并显示新消息数量；查看消息后提醒消失，处理状态仍由本人决定。遇到消息顺序、时间或显示内容无法确认的情况会显示「需要核对」并列为待处理，请打开原会话检查。重复同步与补录旧历史不会重复生成新消息提醒。

快速同步优先检查最新消息：已有确认位置的会话只保存该位置之后的新消息；首次同步会初始化当前可见记录。只有最近一次对当前消息窗口读取完整、平台会话标识与时间均未变化且没有未读提示的会话才会临时复用；每隔最多 3 小时会重新读取，发现异常则不复用。删除操作会让该会话的旧缓存失效。等待中的相同同步任务会合并；运行中再次请求最多保留一个后续重查，避免漏掉同步期间的新消息。账号状态旁显示上次耗时及复用数量。完整历史同步会继续向前读取，但仍遵守本地删除记录；首次最多 20 页，再次同步可逐步向前加载，最多检查 200 页。会话列表每次最多向下检查 300 次，加载不全会提示需要重试。平台返回但页面没有展示的项目、或页面出现但无法与平台记录对应的项目，不会伪装成已读到的消息，也不会推进消息确认基准；这类会话显示「需要核对」或「历史记录尚未完整核实」。历史上限以实际加载情况和平台保留范围为准，并非承诺能恢复所有历史消息。

确认基准只按已核验消息的时间推进，会话列表时间仅用于显示和判断缓存是否可复用；旧基准如领先于已核验消息，会在该会话下次读取时保守修正。不能仅凭这一修复证明旧版本运行期间没有漏掉过历史提醒；存疑时请核对原会话。

「自动同步」默认关闭，可设置为每 30 分钟、1、2 或 6 小时，同步所有已核验账号；只有工作台程序保持运行时才会执行，关闭期间不会实时接收提醒。下次自动同步从上次自动任务结束后重新计算间隔，排队过久也不会刚完成就自动重跑；中断或无法记录结果时，按恢复时的间隔等待。登录过期、同步未完成或消息无法确认时应查看提示并核对。

## 备份与主题

「账号管理」中可创建和恢复本机数据库备份，位置为 `%LOCALAPPDATA%\OwnPublisher\backups`。备份包含数据库中的账号记录、批次和已保存的私信，但不包含独立 Edge 登录资料、数据库以外的图片素材及独立的防重复记录 `%LOCALAPPDATA%\OwnPublisher\restore-guard.sqlite3`；换机前请关闭程序并一同妥善保管。恢复会覆盖当前数据库：请先退出 Codex、关闭其他工作台和命令行窗口，再通过独立浏览器打开工作台恢复，避免旧版后台进程绕过保护。不要手动用备份文件覆盖数据库，这会跳过恢复检查。程序会先自动创建一份恢复前备份，并在恢复后关闭自动同步。

恢复备份会自动开启发布保护：在「账号管理」逐个核对平台作品并查看结果，确认后才可继续发布；新增或更换的账号也须先核对。恢复前已经提交或结果不明的相同图文会继续被拦截；平台发现同名作品时，须另行确认不是重复。若平台列表不能完整读取，发布保护不会自动解除。恢复后在平台外新增或修改作品时，请再次核对，平台列表的读取结果只是核对时的快照。深浅主题保存在本机数据库中，重启后保留。

智能体可通过 MCP 的 `inbox_accounts`、`inbox_conversations` 和 `inbox_messages` 查询本机已同步的数据。会话的 `conversation_key` 由平台身份和会话标识确定，可用于 `inbox_messages(conversation_key=...)`；原数字 `conversation_id` 仍可用。消息提供稳定 `message_id`、平台消息 ID、`timestamp_ms`、时间标签、ID 核验和内容完整性标记；`content_complete=null` 表示无法保证文本完整，`false` 表示媒体或内容可能不完整。会话的 `history_complete`、`history_pages` 用于判断历史是否读全。平台或账号身份改变可能导致稳定标识变化。工作台本机 API 读取需要本机访问会话；这些查询接口不提供发送消息的操作。更新代码后，已运行的 Codex 会话需要重新打开，才能加载新的 MCP 工具。

## 本机使用

如果环境尚未安装，在项目目录的 PowerShell 中运行。需要 Python 3.11、uv 和 Microsoft Edge。

```powershell
uv venv --python 3.11 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.\发布台.ps1 add-account xhs01 xiaohongshu --label "小红书主号"
.\发布台.ps1 login xhs01
.\发布台.ps1 check xhs01
```

首次在打开的独立 Edge 窗口里正常登录，并确认是对应的账号。进入创作者图文入口后窗口会自动关闭。登录数据保存在当前 Windows 用户的 `%LOCALAPPDATA%\OwnPublisher\profiles`，一个别名对应一个浏览器资料目录。别名由你命名，当前登录检查核对创作者页面是否可用，账号昵称由你在首次登录时核对。

CLI 用户可参考 [图文批次示例](./图文批次示例.json) 新建批次。相对图片路径从批次文件所在目录解析。各账号可继承共同文案和图片，也可覆盖内容。小红书的标题最多 20 字、正文最多 1000 字。

```powershell
.\发布台.ps1 preview .\我的图文.json
.\发布台.ps1 publish <批次号> --confirm <批次号>
.\发布台.ps1 status <批次号>
```

需要在发布过程中手动处理登录或验证时，可在发布命令后加 `--interactive`。Codex 的 `publish_batch` 工具也可设置 `interactive=true`，打开独立浏览器供人工处理。验证完成后，除工作台按钮外，也可在另一个 PowerShell 窗口执行 `.\发布台.ps1 continue <批次号>`，或让 Codex 调用 `continue_verification`；取消等待可使用 `.\发布台.ps1 cancel-verification <批次号>` 或 `cancel_verification`。如果智能体请求中断或超时，任务可能仍在后台运行，请先检查工作台记录再决定如何处理。

预览会保存批次并列出各账号实际使用的内容和当时核验的账号。发布时按账号依次执行。同一账号的标题、正文、话题和图片相同，即使修改了时间或声明也会提示重复；完全相同或前次结果待核对时会跳过。仅时间或声明改变且前次已提交时，可在预览中逐账号确认确实需要重复发布。命令行可为明确需要重复的账号传入 `--allow-duplicate-account xhs01`，并同时确认批次；MCP 使用 `allow_duplicate_accounts`。已核验为同一个平台账号的两个别名也会被识别。旧版记录没有保存账号身份摘要，跨别名的历史重复无法全部判断；同一别名的旧记录仍参与去重。每条结果实时写入本地数据库。

已经标记为重复的批次，如确实需要按新时间或声明再次发布，可在核对预览后执行：

```powershell
.\发布台.ps1 publish <批次号> --confirm <批次号> --retry-failed --allow-duplicate-account xhs01
```

小红书提交前会核对上传成功的图片与预览素材逐张对应、顺序一致，检查标题、正文、话题、声明、北京时间和公开范围。原始字节不同但平台仅调整了图片编码或方向时，会比较完整解码像素；分片上传还要求每个分片及最终合并均成功。校验过程中只在内存中处理图片，证据不包含图片内容或登录凭据。如果平台上传方式发生变化导致无法核实，工作台会在提交前停止并提示，不能仅凭图片数量通过。

升级前已生成但尚未提交的旧预览没有账号身份摘要。请先在账号管理中检查账号，再重新生成预览；原有记录不会删除。身份摘要保存在本机，不包含登录凭据；如平台页面无法提供账号身份，工作台会停止提交并提示重新检查。

- `submitted` 表示创作者页面出现提交确认。审核结果和作品可见性在创作者后台核对。
- `failed` 表示提交前失败，或待发送请求已确认被拦截；`login_needed` 表示需要正常登录或人工验证。处理后可用 `--retry-failed` 重试。
- `uncertain` 表示提交后的结果不明确，或程序在执行途中退出。先核对平台作品记录。程序不会重发该条。
- `verifying` 表示正在等待人工处理登录或验证。
- `cancelled` 表示人工等待在提交前取消或超时；处理后可用 `--retry-failed` 重试。

如果平台核对已经找到对应作品，同一任务不能再标记为未提交或重发；即使旧入口留下错误的失败状态，统一发布引擎仍会拦截。

## Codex

MCP 通过标准输入输出运行。若换了电脑或移动了项目，用下面命令重新注册，然后重新打开 Codex 会话。

```powershell
codex mcp add own-publisher -- (Resolve-Path .\.venv\Scripts\python.exe).Path -X utf8 (Resolve-Path .\agent_server.py).Path
```

更新发布台代码后，已经运行的 Codex 会话可能仍连接旧版进程，新的账号核对和验证续接功能不会自动加载。使用智能体发布前，请重新打开 Codex 会话，再核对预览。

可对 Codex 说「用 own-publisher 预览我的图文批次，列出每个账号的昵称、标题和图片。等我确认批次后发布，并逐账号给出结果」。预览中 `identity_verified` 为 `false` 时，请先检查账号并重新生成预览。
